# Эволюция BrainRot — Roblox

Мини-игра-кликер с эволюциями: зарабатывай BrainRot кликами и пассивным доходом, покупай апгрейды, эволюционируй через мем‑стадии, открывай автокликер. Данные игрока сохраняются через DataStore.

## Что внутри
- Серверная логика: клики, пассив, эволюции, магазин, анти‑эксплойт, сохранение
- Клиентский UI: кнопка клика, прогресс‑бар до новой эволюции, магазин апгрейдов, уведомления
- Автокликер (после покупки) и пассивный доход
- Лидерборд (BR и Evo)

## Как запустить через Rojo
1) Установите Roblox Studio (Windows/macOS)
2) Поставьте Rojo:
   - Плагин для Studio: "Rojo" из Roblox Marketplace
   - CLI (по желанию): `rojo` через `aftman`/`foreman` или готовый бинарь
3) Откройте пустой Place в Roblox Studio
4) В терминале (локально) запустите синхронизацию:
   - На машине с проектом выполните: `rojo serve` (если установлен CLI)
5) В Studio откройте плагин Rojo и подключитесь к `default.project.json`
6) Нажмите Play — UI и логика появятся автоматически

Без Rojo (вручную):
- Создайте в Studio соответствующие контейнеры и вставьте скрипты из `src/*` в `ServerScriptService`, `ReplicatedStorage`, `StarterPlayer/StarterPlayerScripts`

## Структура
- `default.project.json` — дерево для Rojo
- `src/ReplicatedStorage/Shared/Config.lua` — баланс и параметры
- `src/ServerScriptService/*` — серверные сервисы и основной скрипт
- `src/StarterPlayer/StarterPlayerScripts/Client.client.lua` — клиентский UI и взаимодействие

## Примечания
- DataStore работает в Live/Team Test. В Studio могут быть ограничения. Скрипт обрабатывает ошибки и использует безопасные попытки сохраниения
- Аудио/анимации заглушены — добавьте свои `SoundId`/анимации в соответствии с правилами Roblox
- Все названия/эстетика — нейтральные и редактируемые в `Config.lua`
